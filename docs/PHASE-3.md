- [x] **مولّد الوجبات** `generator.ts`:
  - 4 وجبات يومياً (فطور 25%، غداء 35%، سناك 15%، عشاء 25%)
  - يختار الأكل حسب الوجبة والنظام الغذائي (نباتي، بدون لاكتوز، ميزانية محدودة)
  - يحسب أفضل كميات بالضبط (بحث شامل على الحصص)، وكل وجبة تعوّض فرق اللي قبلها
  - لو البروتين ضعيف (بقوليات مثلاً) يضيف مصدر بروتين قوي تلقائياً
  - ثابت: نفس اليوم = نفس الوجبات، إلا لو بدّلت
- [x] **صفحة التغذية** `/nutrition` بـ 4 تبويبات:
  - **الوجبات:** بطاقة لكل وجبة، زر "أكلتها" يعبّي حلقات السعرات والماكروز، وزر "بدّل" يجيب وجبة ثانية بنفس الأهداف
  - **الماء:** قارورة متحركة بموجة، أزرار +250 / +330 / +500، سجل اليوم وتراجع. الهدف يزيد 500 مل أيام التمرين
  - **التسوق:** قائمة 7 أيام مجمّعة حسب القسم، علامات صح محفوظة، ومشاركة القائمة (واتساب وغيره)
  - **المكملات:** دليل صريح (كرياتين، واي، فيتامين د، أوميغا 3، كافيين، BCAA) مع حكم واضح لكل واحد
- [x] **الرئيسية:** الحلقات صارت حقيقية (اللي أكلته / الهدف، الماء)، وزر سريع "+ كوب ماء"
- [x] **شريط التنقل:** التغذية صارت بالشريط السفلي، والمكتبة انتقلت لـ "المزيد"
- [x] Dexie v3: جداول mealPlans و waterLogs. الخطة تتحدث تلقائياً لو غيّرت بياناتك (إذا ما أكلت شي من اليوم)
