- [x] **الاستبيان** `/onboarding` (5 خطوات بانتقالات متحركة وشريط تقدم):

  2. الهدف: تنشيف، تضخيم، لياقة، قوة

  4. اختيار أيام التمرين بالضبط (2 إلى 6) + المعدات (جيم / دمبلز / بيت)

  - يضبط الجولات والتكرار والراحة حسب الهدف والخبرة، ويقص التمارين لو الحصة أطول من وقتك
  - أيام الراحة: كارديو خفيف بالتناوب للتنشيف واللياقة، مع يوم راحة كامل دائماً
- [x] **شاشة "خطتك جاهزة"** `/plan-ready`: السعرات، شريط الماكروز، الماء، نوع النظام
- [x] **الجدول الأسبوعي** `/schedule`: شريط الأسبوع (السبت أول بالعربي)، تفاصيل كل يوم، التمارين بالجولات والتكرار، كارديو وراحة، أهداف اليوم، زر تعديل وإعادة بناء
- [x] **الرئيسية** صارت تقرأ خطتك الحقيقية: تمرين اليوم، أو يوم راحة/كارديو مع التمرين الجاي
