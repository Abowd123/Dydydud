# المرحلة 4: وضع التمرين المباشر 🚀 MVP

**المدة:** 30 نوفمبر إلى 13 ديسمبر 2026 • **النسخة:** 1.0.0-mvp

## اللي انسلّم

- [x] **صفحة التمرين** `/workout`: اختيار يوم التمرين (اليوم مختار تلقائياً)، معاينة التمارين والمدة، استكمال حصة شغالة، آخر 5 حصص
- [x] **وضع التمرين المباشر** `/workout/live` (شاشة كاملة بدون شريط التنقل):
  - **إحماء موجّه** 7 حركات (~5 د) بمؤقت يتنقل تلقائياً
  - فيديو التمرين، المطلوب (جولات × تكرار)، **الوزن المقترح**
  - شريط الجولات: المكتملة تبين الوزن × التكرار
  - أزرار + و − كبيرة للوزن والتكرار (خطوة الوزن حسب المعدات: بار 2.5، دمبل 2، جهاز 5)
  - "كيف كانت؟" سهلة / مناسبة / صعبة (تدخل في اقتراح الوزن الجاي)
  - **اسحب لإنهاء الجولة** (يدعم RTL، والضغط مرتين كبديل)
  - **مؤقت راحة دائري** بشاشة كاملة: نبض وصوت بآخر 3 ثواني، اهتزاز، ±15 ثانية، تخطي، ويعرض التمرين الجاي
  - المؤقت مبني على وقت النهاية: دقيق حتى لو قفلت الشاشة
  - **Wake Lock**: الشاشة ما تطفي
  - تنقل بين التمارين، قائمة التمارين، زيادة/حذف جولة، **تبديل التمرين ببديل** لو الجهاز مشغول
  - **تبريد وإطالات** 6 حركات (~4 د)
  - الحصة تنحفظ مع كل ضغطة: لو سكّرت التطبيق ترجع لنفس المكان
- [x] **Progressive Overload مبسط**: كل الجولات وصلت أعلى التكرار وما كانت صعبة ← يزيد الوزن. أغلبها فشلت ← ينزّل. غير كذا ← نفس الوزن
- [x] **شاشة الإنجاز** `/workout/summary/:id`: احتفال Confetti، المدة، الحجم الكلي، الجولات، التكرار، **الأرقام القياسية** (1RM تقديري)، السلسلة، التفاصيل
- [x] **السلسلة 🔥** حقيقية بالرئيسية: عدد الحصص المتتالية بدون ما تفوّت يوم مجدول (الراحة ما تكسرها)
- [x] **سجلك** بصفحة كل تمرين: آخر 5 مرات + أفضل 1RM
- [x] **تحميل مسبق للميديا**: فيديوهات تمارين الأسبوع تنحفظ بالكاش عشان تشتغل بالجيم بدون نت (يحترم وضع توفير البيانات)
- [x] الإعدادات: تشغيل/إيقاف الصوت، الاهتزاز، الإحماء التلقائي
- [x] Dexie v4: جدول sessions مفهرس بالتمارين

## الاختبارات (اشتغلت فعلياً ✅، 56 اختبار)
- `session.test.ts` (17): قراءة التكرار، اقتراح الوزن (5 حالات)، إكمال الجولات ونقل الوزن، نهاية الحصة، إضافة/حذف جولات، التبديل، الملخص والأرقام القياسية، السلسلة

## شروط الإنجاز (MVP)
1. `npm test` كلها ناجحة
2. **حصة كاملة والجوال على وضع الطيران** (بعد ما تفتح التطبيق مرة بالنت)
3. سكّر التطبيق بنص الحصة وافتحه: يرجعك لنفس الجولة
4. الحصة الثانية لنفس التمرين: يقترح وزن أعلى لو خلصت كل التكرارات
5. **جرّبه مع 5 إلى 10 أشخاص حقيقيين** وسجّل ملاحظاتهم قبل المرحلة 5
