**المدة:** 14 إلى 27 ديسمبر 2026 • **النسخة:** 1.1.0

> التطبيق يشتغل **محلي 100%** بدون أي إعداد. المزامنة والإشعارات من السيرفر تتفعل لما تحط مفاتيح Supabase.

## اللي انسلّم

### 📈 شاشة التقدم `/progress`
- ملخص: عدد الحصص، السلسلة، الحجم الكلي، الساعات
- **الوزن:** رسم + متوسط 7 أيام + معدل التغير بالأسبوع (أخضر لو يمشي مع هدفك)
- **تطور القوة:** 1RM تقديري لكل تمرين مع الوقت
- **الحجم الأسبوعي:** آخر 8 أسابيع
- **خريطة الالتزام:** آخر 12 أسبوع
- **القياسات:** خصر، صدر، ذراع، أرداف، رقبة + **نسبة الدهون (US Navy)**
- **صور قبل وبعد:** أمام / جنب / خلف، ضغط تلقائي لـ 1080px، **مقارنة بسلايدر**
- لو وزنك تغير كيلو أو أكثر: زر "حدّث" يعيد حساب سعراتك وخطتك

### ☁️ المزامنة (Supabase)
- **Offline-first:** كل شي ينحفظ بالجوال أول، والمزامنة بالخلفية
- كل كتابة بقاعدة البيانات تنضاف تلقائياً لـ outbox (Dexie hooks) بدون ما نعدل أي شاشة
- رفع ثم سحب، "آخر كتابة تفوز"، ووقت السيرفر هو المرجع
- تتزامن: الملف، الخطة، الحصص، الوجبات، الماء، المفضلة، القياسات، بيانات الصور
- **الصور نفسها ما تنرفع إلا لو فعّلت الخيار**، ولمجلد خاص فيك فقط
- تسجيل الدخول: **رمز 6 أرقام بالإيميل** أو **Google**
- المزامنة تشتغل: عند الدخول، رجوع النت، فتح التطبيق، كل دقيقتين، وبعد أي تغيير بـ 3 ثواني
- **حذف بياناتي من السحابة** (خصوصية)
- الماء صار بمفتاح UUID (ترحيل تلقائي للبيانات القديمة)

### 🔔 التذكيرات `/reminders`
- تذكير التمرين بوقت تختاره (أيام التمرين بس)
- تذكير الماء كل 1 / 2 / 3 ساعات بين وقتين
- **بدون سيرفر:** تذكير والتطبيق مفتوح
- **مع السيرفر:** Web Push يوصلك والتطبيق مقفل (Edge Function + pg_cron كل 15 دقيقة)
- Service Worker مخصص `src/sw.ts` (كاش + إشعارات + فتح الصفحة الصحيحة عند الضغط)

## 🛠️ ربط Supabase (15 دقيقة)

1. أنشئ مشروع على [supabase.com](https://supabase.com) (مجاني)
2. **SQL Editor** ← الصق `supabase/migrations/0001_init.sql` وشغّله
3. **Authentication ← Providers:** فعّل Email (OTP) و Google (اختياري)
4. **Authentication ← URL Configuration:** أضف `https://your-app.vercel.app/account`
5. انسخ `.env.example` إلى `.env` وحط `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY` (من Settings ← API)
6. بـ Vercel: حط نفس المتغيرات في Environment Variables

### الإشعارات من السيرفر (اختياري)
```bash
npx web-push generate-vapid-keys          # انسخ المفتاحين
# حط العام في .env: VITE_VAPID_PUBLIC_KEY
supabase functions deploy send-reminders --no-verify-jwt
supabase secrets set VAPID_PUBLIC_KEY=... VAPID_PRIVATE_KEY=... VAPID_SUBJECT=mailto:you@mail.com CRON_SECRET=$(openssl rand -hex 24)
```
بعدها شغّل `supabase/migrations/0002_cron.sql` بعد ما تغير `<PROJECT_REF>` و `<CRON_SECRET>`.
